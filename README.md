# MealApp 🍽️ (React Native Learning Project)

Welcome to **MealApp**, a mobile application built with **React Native** as part of my learning journey into cross-platform mobile development. This project demonstrates core concepts of React Native, component-based architecture, state management, and navigation. 

The app allows users to browse a collection of meals, apply dietary filters, and view detailed recipes — all within a clean and intuitive interface.

---

## 🚀 Features

- 📚 **Meals Catalogue** – Browse a list of categorized meals (by cuisine/type).
- 🔍 **Meal Details** – View ingredients, steps, and preparation time for each meal.
- ⚙️ **Filters Screen** – Filter meals based on dietary preferences: gluten-free, vegan, vegetarian, and lactose-free.
- ❤️ **Favorites** – Mark and view your favorite meals.
- 📱 **Cross-Platform** – Designed to work on both Android and iOS using React Native.

---

## 🛠️ Technologies Used

- **React Native** (Expo)
- **React Navigation** (Stack & Tab Navigation)
- **React Context API** for state management (Favorites & Filters)
- **Expo CLI** for development and testing
- **JavaScript (ES6+)**
- **Custom Styling** with `StyleSheet` and `Platform` API

## 📂 How to Run the App

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/MealApp-React-Native-Learning.git
   cd MealApp-React-Native-Learning
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the app:
   ```bash
   npx expo start
   ```

4. Scan the QR code using the **Expo Go** app on your mobile device.
